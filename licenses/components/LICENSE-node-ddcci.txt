Scope of Use in Mimonitor Toolbox:
Only the Windows DDC/CI transient error return codes (0xC0262582 through 0xC0262587)
and hardware retry criteria were referenced for robust Win32 DDC/CI communication.
No Node.js addon or V8 runtime dependencies are bundled.
